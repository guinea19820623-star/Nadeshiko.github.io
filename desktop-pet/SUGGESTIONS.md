## 穩定性（需要祐實測）

- 走路有沒有打滑（v0.7.9 的速度是從腳步量出來的）
- 螢幕休眠喚醒後偶爾拎不起來：v0.3.2 加了修復與喚醒快捷鍵 Ctrl+Alt+N
- 高 DPI 縮放、macOS：都還沒實測

## 倉庫大小
- 動畫片段讓 `app/sprites` 從約 28MB 變成約 57MB，下載壓縮檔也從約 29MB 變成約 54MB。之後可以考慮：下載檔改放 GitHub Releases（不進 git 歷史）、片段改用較低的 WebP 品質，或只保留實際播得到的格。
