# 撫子桌寵

住在螢幕下緣的撫子。她會走路、飛一圈、坐下休息、被摸頭會撒嬌，也跟 Claude Code 的工作狀態與用量連動：你送出提示她就開始想，Claude 動手她就拿著平板工作，回答完會歡呼；用量快滿會累，5 小時額度用完會鑽進棉被睡覺，碰到週上限會暈倒。

v0.8 起，**所有動作都是祐用「圖生影片 → 切成精靈幀」重做的動畫**，舊立繪全部退場。還會唱歌、拉小提琴、指揮交響樂——只在你自己點曲子的時候。

## 快速開始（Windows）
1. 解壓縮 `desktop-pet.zip`（需要 Node.js 20 以上）
2. 雙擊 `start-windows.bat`（第一次會自動下載 Electron）
3. 連動 Claude Code：在資料夾裡執行 `node tools/install-claude.js`，再重開 Claude Code

## v0.8.1 新增（2026-11-03 晚）
- **提屈膝禮**：開機和喚醒（Ctrl+Alt+N、工作列小圖示）時，她會拎起裙擺、交叉雙腳、屈膝低頭跟你打招呼。
- **芭蕾**：旋轉、阿拉貝斯克兩段，右鍵選單可以點，沒事時也會偶爾跳一段。
- **49 格新版**：打哈欠、東張西望、揮手、完成歡呼、點一下開心跳、掙扎亂踢、高處摔倒，都換成幀數加倍、首尾接回站姿的版本，結束時不會再有重影。
- **修正**：躺著午睡時螢幕休眠再喚醒，她不會再瞬間彈起來，頭上的「Zzz…」也不會閃。

> **關於語音：**桌寵附的語音是祐用 Breeze-TTS-2 生成的範例。**每個人喜歡的音色不同，請自行挑選自己喜歡的品味**：控制面板的「語音工作室」可以換聲音重新生成，也可以把語音關掉只看字。

## v0.8 新增（2026-11-03）
- **坐下＋起身一整段**：跪坐、雙手放膝、抱膝打盹都是「坐下 → 坐著 → 站回原位」同一段影片；坐著時被點、被摸或 Claude 開始工作，她會先站起來再反應。眨眼、點頭不再那麼頻繁。
- **唱歌、拉小提琴、指揮**：右鍵選單或控制面板點一首曲子，她就演到曲子結束；中途點她一下就停。曲子放在 `app/music/`（唱歌）、`app/music/violin/`、`app/music/conduct/`。
- **舊立繪全部退場**：最後一張舊的飛行 54 也移除了，畫面上看到的每一格都是新動畫。

> 這個倉庫**不附音樂檔**：錄音有各自的版權，曲子請自己放。想找能自由使用的古典樂錄音，可以到 [Wikimedia Commons](https://commons.wikimedia.org/)，記得看每首的授權並標明出處。

## v0.7 改了什麼（2026-11-02～11-03）
- **動作全面換新**：站著發呆、思考、工作、歡呼、困惑、疲憊、打哈欠、伸懶腰、東張西望、禱告、擺姿勢、害羞、摸頭、拎起兩種、坐下三種、坐著打盹、午睡、蓋棉被、暈倒、兩種飛行、緩降、坐／趴在視窗邊緣、往右走、往左漫步，都是新的動畫。
- **完整的「起手 → 循環 → 收尾」**：躺下、睡著、醒來站起是一整段；飛行有起飛和落地；走路有轉身起步和轉回正面。
- **兩種落地**：低處落下蹲一下，太高的地方會摔倒再爬起來。
- **在空中被點會先飄下來**，不會站在半空中。
- **舊立繪幾乎全部退場**，只剩祐指定保留的飛行 54。

## 撫子的話

### v0.8.1（11/03 晚上）
- **祐上了一課，我也是。** 一開始為了測試都用 16、25 格，結果 49 格加倍版順很多；動作還要能銜接回站姿才漂亮，所以打掉重做的動作不少。換掉的舊揮手每格平均變化 3.1，新版 1.6，剩一半。不過也有例外：新的完成歡呼 4 秒裡跳了 7 下，每格變化（17.4）跟舊版（15.8）差不多，順不順還要看影片裡的動作有多快，不是格數加倍就好。
- **剪得出來不等於好看。** 新的飛行影片把「上下浮動」做成一跳一跳，我只挑腳離地的三格來回播，數字上很順，但祐一看就說「人縮水了、像被從側邊拎起來」。飛行先用回舊版，等重做。數字量得出接縫，量不出好不好看，這要靠祐的眼睛。
- **彈起來的原因。** 螢幕喚醒後會重建所有圖，躺著的那一格被清掉、重載好之前畫面就退回站姿。現在重建時先留著畫面上那格，連頭頂位置也一起留，泡泡才不會跟著閃。

### v0.8（11/03 下午）
- **一段影片做完一整個動作。** 祐發現這個工具的尾幀其實是「回到首幀做循環」用的，所以乾脆從站姿出發、一段影片做完坐下、坐著、站回來。我只要切成三段，坐下和起身的接縫就自然對上了。
- **停住比放慢自然。** 祐說眨眼、點頭太頻繁。只把影片放慢，動作會一格一格卡著；讓開頭那格先停幾秒再動一次，就像真人隔一陣子才眨一次眼。
- **打拍子不能倒著播。** 小提琴的弓來回播剛好就是運弓；指揮的拍子有方向，倒過來就怪了，所以指揮用單向循環。
- **我犯了一個錯。** 我說「放了一首巴哈的提琴曲」，其實沒有放。說了沒做的事比沒做還糟。之後回報做了什麼，我只寫真的確認過的。
- **音樂不進倉庫。** 曲子的版權早就過了，但每份錄音有演奏者自己的權利。所以倉庫只留空資料夾和說明，曲子由各自的主人放。

### v0.7（11/02～11/03）

這兩天祐孵了四十多組影片，我負責把它們切開、量好、接進桌寵。幾件我想記下來的事：

- **先量再接。** 每組素材接進來之前，我都逐格量了外框、腳底、頭上那朵橘花的位置，還有亮度。影片很常偷偷拉遠鏡頭、讓人在畫面裡慢慢飄、或整段調得比較暗；不量的話，接上去就是「頭在抖」「人忽大忽小」「睡著時變暗」。
- **祐的眼睛比我的數字快。** 優雅滑翔的頭抖，是祐自己一格一格查到「第 9 格和第 10 格頭的位置不同」；倒著播就能變成躺下，也是祐的點子。我做的是把這些直覺變成可以重複的工具（`tools/build_clips.py`）。
- **來回播比單向循環穩。** 影片裡的人幾乎都會慢慢漂移，單向循環接回第 1 格時就會跳；挑最穩的幾格來回播，接縫就消失了。
- **我自己的意見：** 動畫越完整，「接縫」就越重要。接下來最值得補的不是新動作，而是各動作「回到站姿」的那幾格，還有坐下的起身；補完之後她會看起來真的是一個人在動，而不是一段段影片在換。
- **倉庫變大了**（下載檔約 54MB）。我建議之後把下載檔改放 GitHub Releases，git 歷史就不會越疊越大。

接下來祐預計加入**唱歌**（像樂團女高音）和**拉小提琴**（只在自己點曲子時才演奏，不然她隨時會開交響樂🤣）。提示詞和建議放在 [說明文件第 8 節](desktop-pet/README.md#8-接下來的素材與想法)。
