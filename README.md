# 撫子桌寵

住在螢幕下緣的撫子，會走路、飛行、被摸頭撒嬌，並跟 Claude Code 的工作狀態與用量連動。

![各種狀態](images/states.jpg)

- 下載：[downloads/desktop-pet.zip](downloads/desktop-pet.zip)
- 完整說明：[desktop-pet/README.md](desktop-pet/README.md)
- 網站：<https://guinea19820623-star.github.io/>

## 快速開始（Windows）
1. 解壓縮 `desktop-pet.zip`（需要 Node.js 20 以上）
2. 雙擊 `start-windows.bat`
3. 連動 Claude Code：`node tools/install-claude.js`
